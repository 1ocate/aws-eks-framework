# Roadmap

## Phase 1: foundation

- Define the public variable and output conventions.
- Add Terraform version and provider constraints.
- Implement state bootstrap and network modules.
- Add static checks and secret scanning.

## Phase 2: EKS platform

- Implement the EKS cluster module.
- Add Cilium and Karpenter.
- Add load balancer and storage controllers.
- Add blue and green example roots.

## Phase 3: GitOps

- Bootstrap Argo CD.
- Add optional platform applications.
- Add a neutral sample application.
- Document promotion and rollback.

## Phase 4: release readiness

- Add automated validation and integration tests.
- Complete security and cost reviews.
- Select a license and contribution policy.
- Verify that repository history contains no private material.
